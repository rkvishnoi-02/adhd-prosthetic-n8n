## MVP Features Summary

| Feature | What User Experiences |
|---------|----------------------|
| **Login** | Email magic link (no password to remember) |
| **Onboarding** | 3-question identity capture via chat |
| **Chat** | Clean, minimal interface |
| **@dump** | AI listens without solving |
| **@do** | Task → 3-5 micro-steps |
| **@clarity** | 1-2 questions to think clearly |
| **@ground** | Single physical action for overwhelm |
| **Memory** | AI remembers name + project |
| **Session** | AI remembers recent conversation |
| **Tone** | Always calm, never guilts |

---

## What User FEELS After Using Anchor

- ✅ Calmer
- ✅ Clearer
- ✅ Less overwhelmed
- ✅ Able to start tasks
- ✅ Understood (not judged)
- ✅ Wants to come back

---

## What MVP Does NOT Have (Yet)

| Feature | User Expectation |
|---------|------------------|
| Reminders that persist | ❌ No SMS/Call escalation |
| Habit tracking | ❌ No daily tracking UI |
| Voice input | ❌ Text only |
| Routine builder | ❌ No morning/evening chains |

These come in V2+ based on user feedback.
