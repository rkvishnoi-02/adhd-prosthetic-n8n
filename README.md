# ADHD Prosthetic System

An executive function prosthetic built with n8n workflows that provides external scaffolding for ADHD brains.

## What This Is

This is a complete automated system that acts as an external prefrontal cortex, providing:

- ⏰ **Time-based interventions** - Morning wake sequences, medication reminders, energy management
- 🤖 **24/7 intelligent responses** - Stuck detection, task breakdown, crisis intervention
- 📊 **Pattern learning** - Weekly analysis of your data to optimize the system
- 🎯 **Identity reinforcement** - Celebrates wins by connecting actions to who you ARE
- 🆘 **Crisis safety net** - Detects distress and provides immediate resources

## Core Philosophy

**This is NOT motivation.** This is prosthetic support for impaired executive function.

- Directive, not suggestive (commands, not advice)
- Immediate, not abstract (physical actions, right now)
- Shame-free (normalizes struggles, never punishes)
- Data-driven (shows proof, adjusts based on patterns)
- Identity-focused ("you ARE" not "you should be")

## System Components

### 5 n8n Workflows

1. **Master Scheduler** - Triggers all time-based interventions
2. **Response Handler** - 24/7 listener for user messages
3. **Pattern Analyzer** - Weekly data analysis and optimization
4. **Crisis Monitor** - Safety net for detecting distress
5. **Win Tracker** - Immediate dopamine reinforcement

### Technology Stack

- **n8n** - Workflow automation platform
- **Google Sheets** - Database for all user data
- **Telegram Bot** - User interface (messaging)
- **OpenAI GPT-4** - AI-powered responses and analysis

## Features

### Graduated Independence

The system learns from your consistency:
- **Below 95% consistency**: Directive prompts ("Sit up right now")
- **Above 95% for 30 days**: Interrogative prompts ("Have you done your wake sequence?")
- Automatically adjusts based on your performance

### Intelligent Interventions

- **Task initiation paralysis**: Physical interrupt + smallest first step
- **Overwhelm**: Task decomposition into 5-second actions
- **Rumination**: Pattern interrupt with grounding exercises
- **Crisis detection**: Immediate resources + emergency contact notification

### Data-Driven Optimization

Every Sunday, the Pattern Analyzer:
- Calculates your weekly stats
- Identifies what's working
- Suggests one specific adjustment
- Generates personalized insights

## Safety Features

- **Crisis detection** via sentiment analysis
- **Emergency contact notifications** (with user consent)
- **24/7 helpline resources** (India: Vandrevala Foundation 9999 666 555)
- **Graduated response** based on severity assessment

## Who This Is For

This system is designed for people with ADHD who:
- Struggle with morning wake initiation
- Experience time blindness
- Need external accountability
- Want data-driven self-improvement
- Benefit from immediate positive reinforcement

## Who This Is NOT For

- People seeking a cure (this is assistive technology, not treatment)
- Those preferring minimal structure
- Anyone uncomfortable with AI-powered interventions
- People without access to required technology platforms
